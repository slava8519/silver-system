# Второй мозг в Obsidian

Значок **Второй мозг** на левой ленте настольного Obsidian открывает полную админку текущего хранилища. При первом нажатии плагин проверяет порт и при необходимости запускает локальный сервер. При повторном нажатии возвращает к открытой вкладке. Во вкладке доступны обзор, карта связей, карточки, входящие, проекты, планы и OKR.

Нажмите значок **Открыть в браузере** в заголовке вкладки или выберите эту команду в меню вкладки **…**. В системном браузере откроется тот же раздел. Если вы выбрали задачу на Ганте или перешли к строке источника, в ссылке сохраняется этот выбор. В обоих окнах можно продолжить работу с одними и теми же Markdown-карточками.

В меню вкладки **… → Остановить админку** можно выключить сервер выбранного хранилища, в том числе запущенный вручную обновлённой командой `work`. Остановка доступна и в палитре команд Obsidian при закрытой вкладке. Сохранённые записи сразу доступны в Obsidian и через CLI для Codex или Claude. Чтобы вернуться к веб-интерфейсу, снова нажмите **Второй мозг**.

## Подключение

1. Откройте рабочее хранилище как отдельное хранилище Obsidian. Для учебного примера подойдёт `local/GanttLab`.
2. При установке из пакета файлы уже находятся в `.obsidian/plugins/obsidian-gantt/`. Для отдельного подключения плагина к существующему хранилищу создайте эту папку и скопируйте в неё [manifest.json](manifest.json), [main.js](main.js), [server.js](server.js) и [styles.css](styles.css). При обновлении сохраните имеющийся `data.json`.
3. В **Настройки → Сторонние плагины** включите **Второй мозг**. Если список был открыт во время копирования, обновите его. При обновлении уже включённого плагина выключите и включите его.
4. В настройках **Второй мозг** укажите полный путь к папке программы, внутри которой находится каталог `second_brain`, и нажмите **Применить**. Нужен Python 3.9+ с SQLite FTS5. Если Obsidian не находит Python, укажите полный путь к интерпретатору. По умолчанию плагин использует порт `8766`. Выберите отдельный порт для каждого одновременно работающего хранилища.
5. Нажмите **Второй мозг** на левой ленте. Команда **Открыть Гант** открывает общий каталог проектов и планов с выбранным фильтром **Планы**. Выберите название плана, чтобы перейти к его Ганту.

Закрытие вкладки оставляет сервер доступным в браузере. При отключении плагина или выходе из Obsidian завершается сервер, который запустил сам плагин. Сервер, открытый из терминала, продолжает работать до явной остановки. Восстановление вкладок при следующем запуске Obsidian проверяет состояние сервера. Кнопка **Запустить админку** появляется, если он выключен.

Если порт занят другим хранилищем или деморежимом, вкладка сообщит об этом. Для старого процесса, запущенного до обновления программы, один раз нажмите Ctrl+C в его терминале и снова запустите админку из Obsidian. [Команды рабочей оболочки](../../.agents/skills/brain-vault/SKILL.md)
