# Гант в Obsidian

Плагин открывает планы текущего хранилища в отдельной вкладке настольного Obsidian. На вкладке доступны та же шкала времени и тот же редактор строк, что и в [локальной оболочке](../../README.md). Правки сохраняются в Markdown-карточке задачи. Для работы вкладки нужен запущенный локальный сервер программы.

## Подключение

1. В каталоге настроек выбранного хранилища создайте папку `.obsidian/plugins/obsidian-gantt/`. Если у хранилища собственное имя папки настроек, используйте его.
2. Скопируйте в неё [manifest.json](manifest.json), [main.js](main.js) и [styles.css](styles.css). Перезапустите Obsidian, откройте **Настройки → Сторонние плагины** и включите **Второй мозг · Гант**. При первом подключении разрешите использование сторонних плагинов в этом хранилище.
3. В терминале из каталога программы запустите оболочку для **того же** хранилища. Например, для учебного экземпляра:

   ```sh
   python3 -m second_brain --vault local/GanttLab work --port 8768
   ```

4. В настройках плагина укажите порт сервера. Для примера выше это `8768`, исходное значение плагина — `8766`. Нажмите **Применить**.
5. Нажмите значок Ганта на левой ленте или найдите **Открыть Гант** в палитре команд. Выберите план, затем строку. Нажатие на ссылку карточки открывает исходную запись в Obsidian.

При открытии плагин сверяет полный путь текущего хранилища с путём, который обслуживает сервер на `127.0.0.1`. Если у вас одновременно открыто несколько хранилищ, для каждого запустите оболочку на своём порту. При остановленном сервере вкладка покажет команду запуска для текущего хранилища и кнопку повторного подключения.

Сборка и установка зависимостей для плагина не требуются. Параметр подключения хранится в настройках плагина этого хранилища. В отдельной вкладке использован штатный интерфейс Obsidian [ItemView](https://docs.obsidian.md/Plugins/User+interface/Views).
