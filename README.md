# Второй мозг

«Второй мозг» — это одна рабочая папка на вашем компьютере. Откройте её в **Codex**, чтобы записать факт или задать вопрос с ответом по источникам. Откройте **ту же папку в Obsidian**, чтобы читать и редактировать Markdown, разбирать входящие или работать с Гантом.

Например, в папке `MyVault` рядом живут рабочие проекты, личные заметки и записи о парфюмерии. В `Notes/`, `Projects/` и других разделах лежат ваши материалы. Внутри того же хранилища находятся программа (`.runtime/`), навыки Codex (`.agents/skills/`) и, если вы его подключили, плагин Obsidian (`.obsidian/plugins/obsidian-gantt/`). Стартовая страница — `Home.md`.

## Установка

Распакуйте `second-brain.zip` в отдельную папку. Откройте терминал там, где лежит `install.py`, и укажите папку для записей. Нужен Python 3.9 или новее с SQLite FTS5. В Windows вместо `python3` можно использовать `py -3`. [Скачать Python](https://www.python.org/downloads/)

```sh
python3 install.py "../MyVault"
```

Откройте полученную папку `MyVault` в Codex или Obsidian. Стартовая страница — `Home.md`. Программа и руководства находятся в `.runtime/`, все навыки — в одном каталоге `.agents/skills/` в корне хранилища. Для учебного хранилища с примерами укажите другую новую папку и добавьте `--demo`.

```sh
python3 install.py "../Учебный пример" --demo
```

### Одним сообщением в Codex или Claude Code

Откройте в клиенте папку для записей. Если у вас уже есть ZIP, укажите, где он лежит. Следующий запрос подходит и для установки из исходников.

```text
Установи «Второй мозг» в открытую папку проекта. Используй мой second-brain.zip,
если я передал его. Иначе получи исходники https://github.com/slava8519/silver-system
по точному SHA текущей main во временный каталог и собери пакет командой
python3 tools/build_package.py. Подбери Python 3.9+ с SQLite FTS5.
Распакуй ZIP отдельно от папки для записей. Из распакованного пакета запусти
install.py с абсолютным путём к открытой папке. Если программа уже установлена,
сначала сравни версии и сохрани мои ручные правки. После установки запусти
из .runtime команду python3 -m second_brain --vault .. overview --brief.
Проверь Home.md, корневые .agents/skills и файлы плагина Obsidian.
Покажи путь к хранилищу и результат проверки.
```

### Сборка из исходников

Из корня дерева исходников выполните команду ниже. Готовый пакет появится в `dist/second-brain.zip`. Его можно перенести на другой компьютер и установить без Git и доступа к сети.

```sh
python3 tools/build_package.py
```

### Обновление из пакета

Сначала проверьте новый пакет на копии хранилища. Для обновления рабочего хранилища остановите его локальную админку, распакуйте ZIP отдельно и запустите тот же установщик с путём к рабочей папке. Затем снова откройте админку. [Оценка совместимости](#проверить-обновление)

```sh
python3 install.py "../MyVault"
```

Для пакетных установок версии файлов сверяются по `.runtime/package-manifest.json`. При конфликте установщик укажет файл для сверки. Старой ручной установке с отличающимися файлами программы может понадобиться новый каталог вне хранилища для резервной копии заменяемых файлов.

```sh
python3 install.py "../MyVault" --backup-dir "../MyVault-before-update"
```

При переходе со старой раскладки установщик сверяет навыки в `.runtime/.agents/skills/` с корневыми и переносит их в `.agents/skills/`. Если один навык вручную изменён в обеих папках по-разному, сначала объедините нужные правки и повторите установку. Резервная копия заменяемых компонентов содержит файлы программы. Для резервирования самих записей сохраните отдельную копию хранилища.

### Проверка запуска

Откройте терминал в папке хранилища. Эти команды покажут его состояние и проверят записи. Ниже в руководстве команды также выполняются из `.runtime`.

```sh
cd .runtime
python3 -m second_brain --vault .. overview --brief
python3 -m second_brain --vault .. check
```

## Первый запуск с Codex

Откройте `MyVault` в Codex и попросите сохранить первую заметку.

> $brain-start Запиши в этом хранилище, что запасной термометр лежит в зелёном ящике. Покажи, где это записано.

В следующем чате, открытом для той же папки, спросите «Где лежит запасной термометр? Дай ссылку на строку». Codex сможет найти ответ, даже если браузер и Obsidian закрыты. [Навык первого запуска](.agents/skills/brain-start/SKILL.md) · [Какие ещё вопросы можно задавать](docs/guide.md#как-ии-выбирает-навык)

## Сохранить свою первую запись

Ту же операцию можно выполнить из терминала. Создайте заметку один раз, затем задайте вопрос.

```sh
python3 -m second_brain --vault .. create note "Домашняя аптечка" --body "Запасной термометр лежит в зелёном ящике."
python3 -m second_brain --vault .. ask "Где лежит запасной термометр?" --brief --limit 1
```

В поле `answer` будет текст «Запасной термометр лежит в зелёном ящике.». В `source.path` указан файл `Notes/Домашняя аптечка.md`, а в `source.start` и `source.end` — строки источника. В этом примере обе равны 8. Для проверки выполните команду.

```sh
python3 -m second_brain --vault .. read "Notes/Домашняя аптечка.md" 8 8
```

## Работа в Obsidian

1. Выберите **Открыть папку как хранилище** и укажите `MyVault`. Откройте `Home.md` или перейдите прямо к своей заметке в `Notes/`.
2. В настройках сторонних плагинов включите **Второй мозг**. Установщик уже поместил его файлы в `.obsidian/plugins/obsidian-gantt/`. Кнопка **Второй мозг** открывает админку и Гант. [Подключение и настройки плагина](plugins/obsidian-gantt/README.md#подключение)
3. Для новой установки путь к программе уже задан. Если вы перенесли хранилище, укажите его новую папку `.runtime` в поле **Папка программы** и нажмите **Применить**. Нажмите **Второй мозг** на левой ленте.

Для работы в браузере запустите админку из терминала.

```sh
python3 -m second_brain --vault .. work
```

Откройте напечатанный адрес, обычно [127.0.0.1:8766](http://127.0.0.1:8766/). Во **Входящих** можно добавить текст, файл или скриншот. В **Карточках** кнопка **Редактировать** открывает Markdown на всю рабочую область. В сохранённом отчёте эта кнопка называется **Редактировать текст**. Чтобы завести свою тему, выберите **Карточки → Создать карточку → Направление**. Для остановки сервера в терминале нажмите **Ctrl+C**.

## Попробовать на примерах

Если вы установили учебный пример с `--demo`, откройте путеводитель в этом же хранилище.

```sh
python3 -m second_brain --vault .. demo
```

Откройте адрес из терминала, обычно [127.0.0.1:8765](http://127.0.0.1:8765/). Выберите **Личное**, вопрос о запасном ключе и **Открыть источник**. В памятке вы увидите строку «Запасной ключ хранится в синем чехле». Там же есть решения двух ИТ-проектов и наблюдение о парфюмерной пробе.

Если у вас уже есть рабочие записи, установите демо в отдельную папку. Для перехода от демо к своим записям нажмите **Убрать демоданные**. Предпросмотр покажет, сколько учебных файлов попадёт в архив и сколько останется из-за ваших правок или ссылок. [Переход к своим записям](docs/guide.md#убрать-демоданные-и-оставить-своё)

## Если запуск не удался

| Что вы видите | Что сделать |
| --- | --- |
| `No module named second_brain` | Откройте терминал в `MyVault/.runtime`. Проверьте, что там есть `second_brain/__main__.py`. |
| `no such module: fts5` | Используйте сборку Python с SQLite FTS5. Проверить текущую сборку можно командой ниже. |
| Порт занят | Для запуска из терминала укажите другой порт, например `work --port 8776`, и перейдите по адресу из вывода. В плагине Obsidian порт задаётся в настройках. |

```sh
python3 -c "import sqlite3; sqlite3.connect(':memory:').execute('CREATE VIRTUAL TABLE probe USING fts5(body)'); print('FTS5 OK')"
```

## Проверить обновление

Откройте рабочую папку в Codex и задайте вопрос.

> $brain-update Проверь, что изменилось в репозитории второго мозга. Безопасно ли обновиться с моими настройками и правками навыков?

Codex проверит текущий коммит в GitHub и сравнит с ним установленную программу, навыки и файлы плагина Obsidian. Вы получите ссылку на версию, оценку совместимости и, если понадобится, план обновления. Проверка сохраняет рабочую папку в исходном состоянии. Если хранилище собрано из ZIP и точная версия неизвестна, в ответе будут указаны отличия и что нужно выяснить перед заменой файлов.

Если ваша установка появилась раньше навыка, укажите Codex путь к каталогу `.agents/skills/brain-update/` в отдельно скачанной копии проекта и путь к своему хранилищу. [Инструкция навыка](.agents/skills/brain-update/SKILL.md)

## Что ещё можно делать

- Сохранить оригинал встречи, связать решение с проектом и найти его по источнику. [Разбор входящих](docs/guide.md#разобрать-встречу-и-открыть-карточку-человека)
- Включить одну задачу в несколько планов и вести её сроки в общей карточке. [Задачи и планы](docs/guide.md#одна-задача-в-двух-планах) · [Редактор Ганта](docs/gantt.md)
- Подготовить обзор закрытой недели или отчёт по своему шаблону. [Недельный обзор](docs/guide.md#недельный-обзор) · [Отчёты и шаблоны](docs/guide.md#отчёты-и-шаблоны)
- Проверить, сохранились ли оригиналы и куда ведут ссылки из карточек. [Проверка хранилища](docs/vault-check.md)

Установка и обновление выполняются из одного ZIP. Для открытой альфы предстоит проверить установку и восстановление на чистых macOS и Windows. Примеры с `local/…` в справочнике и тесты предназначены для запуска из дерева исходников. [Дорожная карта](ROADMAP.md#порядок-поставок) · [Как запустить тесты](docs/guide.md#проверки-проекта)
