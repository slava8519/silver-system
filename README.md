# Второй мозг

«Второй мозг» хранит заметки, решения и проекты в обычных Markdown-файлах на вашем компьютере. Запишите, где лежит запасной ключ или о чём договорилась команда. Когда понадобится вспомнить, задайте вопрос своими словами и откройте строку, на которой основан ответ.

В одном **хранилище** можно вести несколько **направлений**, например работу, дом и парфюмерию. Локальная веб-страница помогает собирать материалы и видеть связи. Те же файлы можно редактировать в Obsidian, искать из терминала или поручить их разбор Codex.

## Установка

Понадобятся **Python 3.9 или новее** с поддержкой SQLite FTS5 и браузер для веб-интерфейса. Программа запускается из исходников и использует стандартную библиотеку Python. [Скачать Python](https://www.python.org/downloads/)

1. [Скачайте ZIP с GitHub](https://github.com/slava8519/silver-system/archive/refs/heads/main.zip), распакуйте его и откройте терминал в папке `silver-system-main`. Внутри должны быть `README.md` и каталог `second_brain`. Если пользуетесь Git, получите ту же программу командами ниже.

   ```sh
   git clone https://github.com/slava8519/silver-system.git
   cd silver-system
   ```

2. Проверьте Python и доступность команд. В Windows PowerShell, если Python запускается через `py -3`, подставляйте `py -3` вместо `python3` во всех примерах.

   ```sh
   python3 --version
   python3 -m second_brain --help
   ```

Все дальнейшие команды выполняются из этой папки. Путь после `--vault` указывает, **где лежат записи**. Ниже для демо и собственных записей используются две разные папки внутри `SecondBrain` в вашем домашнем каталоге.

## Попробовать на примерах

Чтобы посмотреть, как работает поиск по записям, запустите путеводитель. При первом запуске выберите путь к **ещё не существующей** папке. Команда сама создаст учебное хранилище.

```sh
python3 -m second_brain --vault "~/SecondBrain/DemoVault" demo
```

Откройте адрес из терминала, обычно [127.0.0.1:8765](http://127.0.0.1:8765/). Выберите **Личное**, затем вопрос о запасном ключе. Нажмите **Открыть источник**, чтобы увидеть строку «Запасной ключ хранится в синем чехле». В том же демо можно проверить решения двух ИТ-проектов и найти наблюдение по парфюмерной пробе. Для этого достаточно браузера.

Оставьте терминал открытым, пока работаете в браузере. Чтобы остановить сервер, нажмите **Ctrl+C**. При следующем запуске укажите тот же путь.

## Сохранить свою первую запись

Выберите отдельную папку для своих записей. Подготовьте её и один раз создайте заметку. Вместо примера можно записать свой факт.

```sh
python3 -m second_brain --vault "~/SecondBrain/MyVault" init
python3 -m second_brain --vault "~/SecondBrain/MyVault" create note "Домашняя аптечка" --body "Запасной термометр лежит в зелёном ящике."
```

Теперь задайте вопрос. Эту команду можно повторять, в том числе после правок в заметке.

```sh
python3 -m second_brain --vault "~/SecondBrain/MyVault" ask "Где лежит запасной термометр?" --brief --limit 1
```

В поле `answer` будет текст «Запасной термометр лежит в зелёном ящике.» В `source.path` указан файл `Notes/Домашняя аптечка.md`, а в `source.start` и `source.end` — первая и последняя строки цитаты. В этом примере обе равны 8. Откройте файл или прочитайте строку из терминала.

```sh
python3 -m second_brain --vault "~/SecondBrain/MyVault" read "Notes/Домашняя аптечка.md" 8 8
```

Чтобы открыть **рабочую админку** этого же хранилища, выполните команду и перейдите по напечатанному адресу, обычно [127.0.0.1:8766](http://127.0.0.1:8766/).

```sh
python3 -m second_brain --vault "~/SecondBrain/MyVault" work
```

Во **Входящих** можно вставить текст встречи, добавить файл или скриншот для последующего разбора. Чтобы завести свою тему, откройте **Карточки → Создать карточку** и выберите тип **Направление**. Когда вы добавите к нему записи или проекты, они появятся на **Карте связей**.

## Первый запуск с Codex

Откройте в Codex **папку программы**, содержащую `.agents/skills/`, и отправьте сообщение.

> $brain-start Помоги мне начать пользоваться вторым мозгом.

Навык предложит пройти демо или начать со своих записей. Если у вас уже есть папка для записей, укажите её в сообщении. Для своей первой заметки можно сразу дать и путь, и факт.

> $brain-start Моё хранилище — ~/SecondBrain/MyVault. Запиши, что запасные батарейки лежат в верхнем ящике стола. Покажи, где это записано.

В следующих чатах указывайте путь к тому же хранилищу. Например, спросите «Где лежат запасные батарейки? Дай ссылку на строку» или попросите «Разбери новые материалы во Входящих». Если клиенту нужен файл инструкции, укажите ему навык и папку программы. [Инструкция навыка первого запуска](.agents/skills/brain-start/SKILL.md) · [Примеры запросов для других навыков](docs/guide.md#как-ии-выбирает-навык)

## Работа в Obsidian

Выберите **Открыть папку как хранилище** и укажите `MyVault`. Откройте `Home.md` или перейдите прямо к своей заметке в `Notes/`. При следующем поиске программа прочитает изменения, сохранённые в Markdown. Если хотите открывать админку и Гант прямо в настольном Obsidian, подключите плагин проекта. [Установка плагина](plugins/obsidian-gantt/README.md#подключение)

## Если запуск не удался

| Что вы видите | Что сделать |
| --- | --- |
| `No module named second_brain` | Перейдите в папку программы, где лежит этот README, и снова выполните команду. |
| `no such module: fts5` | Используйте сборку Python с поддержкой SQLite FTS5. Команда ниже проверяет именно тот интерпретатор, из которого вы запускаете проект. |
| Порт занят | Добавьте другой порт после команды, например `work --port 8776`, и откройте адрес, который появится в терминале. |

```sh
python3 -c "import sqlite3; sqlite3.connect(':memory:').execute('CREATE VIRTUAL TABLE probe USING fts5(body)'); print('FTS5 OK')"
```
