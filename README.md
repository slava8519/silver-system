# Второй мозг

«Второй мозг» — это одна рабочая папка на вашем компьютере. Откройте её в **Codex**, чтобы записать факт или задать вопрос с ответом по источникам. Откройте **ту же папку в Obsidian**, чтобы читать и редактировать Markdown, разбирать входящие или работать с Гантом.

Например, в папке `MyVault` рядом живут рабочие проекты, личные заметки и записи о парфюмерии. В `Notes/`, `Projects/` и других разделах лежат ваши материалы. Внутри того же хранилища находятся программа (`.runtime/`), навыки Codex (`.agents/skills/`) и, если вы его подключили, плагин Obsidian (`.obsidian/plugins/obsidian-gantt/`). Стартовая страница — `Home.md`.

## Установка

### Одним сообщением в Codex или Claude Code

Откройте в **Codex** или **Claude Code** папку, где хотите вести записи. Скопируйте блок целиком и отправьте в чат проекта. Название папки и пути подставлять не нужно.

```text
Установи «Второй мозг» из https://github.com/slava8519/silver-system прямо в открытую папку
проекта. Она и есть корень моего хранилища. Сам выполни установку и проверь результат.

1. Запомни абсолютный путь проекта. Подбери Python 3.9+ и проверь SQLite FTS5 созданием
   виртуальной таблицы в памяти. При необходимости подготовь Python локально для проекта.
2. Если уже есть .runtime/second_brain/, проверь эту установку по шагу 6. При полном комплекте
   на этом закончи. При неполной установке укажи, чего не хватает; дополняй только из
   подтверждённой версии этой установки. Иначе скачай текущую main во временную папку вне
   проекта через Git или ZIP по SHA. Запомни SHA. Сохрани мои записи и настройки. Если
   установка требует замены моего файла, укажи конфликтующий путь до внесения изменений.
3. В .runtime/ выбранной папки скопируй second_brain/, examples/, docs/, plugins/, .agents/,
   README.md и ROADMAP.md из исходников. Навыки brain-* скопируй также в корневую
   .agents/skills/. Из .runtime запусти найденным Python: -m second_brain --vault .. init.
   Создай рабочее хранилище без демоданных.
4. В корневом AGENTS.md один раз допиши, как выбрать и прочитать .agents/skills/<имя>/SKILL.md
   и запускать из .runtime команду «python -m second_brain --vault ..», подставив найденный
   Python. Укажи рабочую команду Python и SHA установки. В корневой CLAUDE.md один раз добавь
   строку @AGENTS.md. Сохрани прежний текст обоих файлов.
5. Скопируй manifest.json, main.js, server.js и styles.css из .runtime/plugins/obsidian-gantt/
   в .obsidian/plugins/obsidian-gantt/. В новом data.json плагина запиши programDir
   (абсолютный путь к .runtime) и python (значение sys.executable). Существующие настройки
   сохрани.
6. Из .runtime выполни тем же Python: -m second_brain --vault .. overview --brief. Проверь
   Home.md, все поставляемые brain-*/SKILL.md в корневой .agents/skills/ и файлы плагина. Если
   клиент запросит разрешение на запись, например в .agents/, запроси доступ к этому пути и
   заверши проверку после разрешения. Покажи путь к готовому хранилищу, результат проверки и
   как включить «Второй мозг» в настольном Obsidian.
```

**Если у вас уже есть собранное хранилище**, откройте в Codex папку с `Home.md` и `.agents/` и переходите к [первой записи](#первый-запуск-с-codex). Для запуска программы нужен Python 3.9 или новее с SQLite FTS5. Веб-интерфейс открывается в браузере или в настольном Obsidian. [Скачать Python](https://www.python.org/downloads/)

### Ручная установка из ZIP

На GitHub доступны исходники. Из них можно вручную собрать новое хранилище. Ниже оно называется `MyVault`. Для первой установки выберите свободное имя. В Windows PowerShell можно заменить `python3` на `py -3`.

1. Скачайте и распакуйте архив. Откройте терминал в распакованной папке `silver-system-main`, в которой видны `README.md` и каталог `second_brain/`. [Скачать ZIP исходников](https://github.com/slava8519/silver-system/archive/refs/heads/main.zip)
2. Для своих записей выполните команду ниже. Рядом с распакованной папкой появится `MyVault` со стартовыми страницами. Если хотите начать с учебных записей, в этой команде замените `init` на `examples`. Для `examples` папка назначения должна ещё не существовать.

   ```sh
   python3 -m second_brain --vault "../MyVault" init
   ```

3. Внутри `MyVault` создайте папку `.runtime`. Скопируйте в неё из распакованного архива каталоги `second_brain/`, `examples/`, `docs/`, `plugins/`, `.agents/` и файлы `README.md`, `ROADMAP.md`. Скопируйте также каталог `.agents/` в **корень** `MyVault`, чтобы Codex видел навыки при открытии хранилища. Если каталоги с точкой не видны, включите показ скрытых файлов.
4. В корне нового `MyVault` создайте текстовый файл `AGENTS.md` со следующей инструкцией. Если вы используете `py -3`, подставьте его и здесь.

   ```markdown
   Рабочее хранилище — папка с этим AGENTS.md. Выбирай навык из .agents/skills/.
   Для команд этого хранилища используй рабочий каталог .runtime и префикс `python3 -m second_brain --vault ..`.
   Пути записей в ответе CLI отсчитываются от корня хранилища. Документация программы, включая README.md и plugins/, лежит в .runtime/.
   ```

5. Откройте **новый терминал в корне `MyVault`** и проверьте установку. Команда напечатает имя хранилища и число карточек. Для нового рабочего хранилища счётчики равны нулю, а для учебного в поле `direction` будет 3.

   ```sh
   cd .runtime
   python3 -m second_brain --vault .. overview --brief
   ```

Дальше для повседневной работы достаточно папки `MyVault`. Во всех командах ниже терминал открыт в её подпапке `.runtime`, а `--vault ..` указывает на само хранилище.

## Первый запуск с Codex

Откройте `MyVault` в Codex и попросите сохранить первую заметку.

> $brain-start Запиши в этом хранилище, что запасной термометр лежит в зелёном ящике. Покажи, где это записано.

В следующем чате, открытом для той же папки, спросите «Где лежит запасной термометр? Дай ссылку на строку». Codex сможет найти ответ, даже если браузер и Obsidian закрыты. [Навык первого запуска](.agents/skills/brain-start/SKILL.md) · [Какие ещё вопросы можно задавать](docs/guide.md#как-ии-выбирает-навык)

## Сохранить свою первую запись

Ту же операцию можно выполнить из терминала. Создайте заметку один раз, затем задайте вопрос.

```sh
python3 -m second_brain --vault .. create note "Домашняя аптечка" --body "Запасной термометр лежит в зелёном ящике."
python3 -m second_brain --vault .. ask "Где лежит запасной термометр?" --brief --limit 1
```

В поле `answer` будет текст «Запасной термометр лежит в зелёном ящике.». В `source.path` указан файл `Notes/Домашняя аптечка.md`, а в `source.start` и `source.end` — строки источника. В этом примере обе равны 8. Для проверки выполните команду.

```sh
python3 -m second_brain --vault .. read "Notes/Домашняя аптечка.md" 8 8
```

## Работа в Obsidian

1. Выберите **Открыть папку как хранилище** и укажите `MyVault`. Откройте `Home.md` или перейдите прямо к своей заметке в `Notes/`.
2. Чтобы открывать админку и Гант внутри настольного Obsidian, скопируйте `manifest.json`, `main.js`, `server.js` и `styles.css` из `MyVault/.runtime/plugins/obsidian-gantt/` в `MyVault/.obsidian/plugins/obsidian-gantt/` и включите **Второй мозг** в настройках сторонних плагинов. В уже подключённом хранилище сразу переходите к кнопке **Второй мозг**. [Подключение и настройки плагина](plugins/obsidian-gantt/README.md#подключение)
3. При первом подключении в поле **Папка программы** укажите полный путь к `MyVault/.runtime` и нажмите **Применить**. Если вы перенесли хранилище, обновите этот путь. Нажмите **Второй мозг** на левой ленте.

Для работы в браузере запустите админку из терминала.

```sh
python3 -m second_brain --vault .. work
```

Откройте напечатанный адрес, обычно [127.0.0.1:8766](http://127.0.0.1:8766/). Во **Входящих** можно добавить текст, файл или скриншот. Чтобы завести свою тему, выберите **Карточки → Создать карточку → Направление**. Для остановки сервера в терминале нажмите **Ctrl+C**.

## Попробовать на примерах

Если при установке вы выбрали `examples`, откройте путеводитель в этом же хранилище.

```sh
python3 -m second_brain --vault .. demo
```

Откройте адрес из терминала, обычно [127.0.0.1:8765](http://127.0.0.1:8765/). Выберите **Личное**, вопрос о запасном ключе и **Открыть источник**. В памятке вы увидите строку «Запасной ключ хранится в синем чехле». Там же есть решения двух ИТ-проектов и наблюдение о парфюмерной пробе.

Если у вас уже есть рабочие записи, для знакомства с демо выберите другое имя папки на шаге 2. Для перехода от демо к своим записям кнопка **Убрать демоданные** показывает, какие примеры попадут в архив. У текущей сборки есть ограничение. Очистка учитывает ссылки из служебных файлов и может предложить сохранить все восемь учебных файлов. Чтобы начать с пустого хранилища, при установке выберите `init`. [Переход к своим записям](docs/guide.md#убрать-демоданные-и-оставить-своё)

## Если запуск не удался

| Что вы видите | Что сделать |
| --- | --- |
| `No module named second_brain` | Откройте терминал в `MyVault/.runtime`. Проверьте, что там есть `second_brain/__main__.py`. |
| `no such module: fts5` | Используйте сборку Python с SQLite FTS5. Проверить текущую сборку можно командой ниже. |
| Порт занят | Для запуска из терминала укажите другой порт, например `work --port 8776`, и перейдите по адресу из вывода. В плагине Obsidian порт задаётся в настройках. |

```sh
python3 -c "import sqlite3; sqlite3.connect(':memory:').execute('CREATE VIRTUAL TABLE probe USING fts5(body)'); print('FTS5 OK')"
```

## Проверить обновление

Откройте рабочую папку в Codex и задайте вопрос.

> $brain-update Проверь, что изменилось в репозитории второго мозга. Безопасно ли обновиться с моими настройками и правками навыков?

Codex проверит текущий коммит в GitHub и сравнит с ним установленную программу, навыки и файлы плагина Obsidian. Вы получите ссылку на версию, оценку совместимости и, если понадобится, план обновления. Проверка сохраняет рабочую папку в исходном состоянии. Если хранилище собрано из ZIP и точная версия неизвестна, в ответе будут указаны отличия и что нужно выяснить перед заменой файлов.

Если ваша установка появилась раньше навыка, укажите Codex путь к каталогу `.agents/skills/brain-update/` в отдельно скачанной копии проекта и путь к своему хранилищу. [Инструкция навыка](.agents/skills/brain-update/SKILL.md)
