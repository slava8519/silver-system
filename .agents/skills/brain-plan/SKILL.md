Из папки программы запускай `python3 -m second_brain --vault "$VAULT"` с командой для выбранного хранилища.

Когда решение зависит от «меня» или «моей команды», прочитай `owner-context --limit 5`. Для «кому из моих поручить» сопоставь участников с подтверждёнными ролями по задаче. Для доступности и назначения нужны отдельные основания. [Состав и источники](../brain-person/references/teams.md)

Для итога периода, закрытия плана и сопоставления с текущими датами открой [закрытие цикла](references/cycles.md). Для вех, зависимостей и вопроса «что сдвинется, если…» открой [сценарии плана](references/dependencies.md). Для прогноза или факта одной работы открой [даты задачи](references/schedule.md). Для «Коротко», «Последнее» и ручных правок используй [команды Ганта](references/gantt.md).

Если владелец ведёт OKR и просит связать работы с целью, посмотреть или записать измерение, открой [ключевые результаты и их источники](references/okr.md).

- Найди задачу через `task-list --match "часть названия" --limit 5`. Если известен проект или его алиас, найди его ID через `list --type project --match "имя" --limit 3`, затем вызови `task-list --project ID`. План ищи через `plan-list --match "название"`. Тёзок различай по ID, проекту и направлению.
- Для новой задачи используй `task-create "название" --request-id КЛЮЧ`. Добавляй `--project ID`, `--direction ID` и `--due YYYY-MM-DD` только по смыслу запроса. План создаётся через `plan-create "название" --request-id КЛЮЧ`. У каждого запроса создания свой ключ, при повторе того же запроса используй прежний.
- Включи существующую задачу в каждый выбранный активный план через `plan-add ID_ПЛАНА ID_ЗАДАЧИ`. Команда `plan-show ID_ПЛАНА` показывает работы с датами активного плана или снимок закрытого. Для следующей страницы есть `--offset`.
- Для переноса согласованного срока используй `task-due ID_ЗАДАЧИ --date YYYY-MM-DD` (для снятия — `--clear`). Предпросмотр покажет прежнюю и предложенную даты, планы и `revision`. Если владелец просил перенести срок, повтори команду с `--apply РЕВИЗИЯ_ПРЕДПРОСМОТРА`. При конфликте сверь свежую карточку и намерение владельца.
- После переноса проверь затронутые активные планы через `plan-show ID_ПЛАНА --task ID_ЗАДАЧИ`. Сверь ID и дату, укажи путь карточки и `dueLine`, когда срок задан. История переносов доступна через `task-history ID_ЗАДАЧИ --limit 5`.
