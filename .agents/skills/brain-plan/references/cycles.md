# Итог и закрытие цикла

- Найди план через `plan-list --match "название" --limit 5`. Для просьбы «покажи итог перед закрытием» вызови `plan-close ID_ПЛАНА --limit 5`. Команда вернёт состав работ, вехи, известные даты и `revision`. При `truncated: true` следующая страница доступна через `--offset`. Пустой факт завершения означает, что дата выполнения ещё не записана.
- По просьбе закрыть выбранный цикл выполни `plan-close ID_ПЛАНА --apply REV` с ревизией его предпросмотра. Закрывается весь план, включая строки за пределами показанной страницы. При конфликте перечитай итог и сверь изменившиеся данные с намерением владельца. В результате проверь `status: closed` и `closedAt`.
- Для вопроса о прошлом периоде используй `plan-show ПЛАН --task РАБОТА`. Закрытый план хранит даты на момент закрытия. Сошлись на `path` плана и `snapshotLine` строки. Для сравнения с сегодняшней оценкой вызови `task-schedule РАБОТА` с тем же ID и сошлись на текущий путь и строку поля.
- При переходе в следующий цикл используй `plan-create "название" --request-id КЛЮЧ` или выбери существующий активный план. По просьбе владельца добавь в него нужные работы через `plan-add НОВЫЙ_ПЛАН РАБОТА` с их прежними ID.
