# Согласованный срок, прогноз и факт завершения

Используй CLI выбранного хранилища. Найди ID задачи и прочитай `task-schedule ID`. В ответе `due` — согласованный срок, `forecast` — ожидаемая дата завершения, `completed` — подтверждённая дата результата. Пустое поле означает «не указано».

- Для прогноза вызови `task-schedule ID --forecast YYYY-MM-DD`. Если есть основание в карточке, добавь `--source "Notes/имя.md" --line N`, при необходимости `--quote "точная цитата"`. Для снятия прогноза используй `--clear-forecast`. Изменяй `due` через `task-due` только при изменении самой договорённости.
- Факт завершения требует основания. Для `task-schedule ID --completed YYYY-MM-DD` укажи строку, где подтверждены результат и дата. Если владелец сам сообщил о выполнении и дате, передай `--owner-confirmed --reason "что подтвердил владелец"`. Так же обоснуй исправление или снятие факта через `--clear-completed`. Прошедший срок или прогноз сами по себе не подтверждают результат.
- Команда сначала показывает прежнее и новое значения, затронутые планы и `revision`. При просьбе только посмотреть верни предпросмотр. Для запрошенной записи повтори команду с теми же аргументами и `--apply REV`. При конфликте перечитай задачу и основание, сверь намерение с новой версией.
- Для проверки прочитай `plan-show ID_ПЛАНА --task ID_ЗАДАЧИ` в каждом затронутом плане. Сопоставь три даты и укажи путь и строки заполненных полей. История прогноза и факта доступна через `task-schedule ID --history --limit 3`.
