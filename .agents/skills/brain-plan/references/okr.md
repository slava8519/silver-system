# Цель и измеримый ключевой результат

Для составных условий, исходного значения, расчёта готовности и вложенных работ см. [критерии, веса и дерево](okr-progress.md).

Используй CLI выбранного хранилища. В плане периода может быть несколько целей. У каждой цели есть направление и свой ID. Ключевой результат хранит ссылку на цель, единицу измерения, необязательный ориентир, ссылки на работы и историю измерений.

- Найди период через `plan-list --match "название" --limit 5` или создай его через `plan-create "IV квартал" --request-id КЛЮЧ`. Найди направление через `list --type direction --match "название"`. Создай качественную цель через `okr-objective-create "Сократить время восстановления" --plan ПЛАН --direction НАПРАВЛЕНИЕ --request-id КЛЮЧ`. Для каждой новой операции выбирай свой ключ.
- Создай измеримый результат через `okr-create "Время восстановления на стенде" --objective-id ЦЕЛЬ --unit мин --target 15 --task ЗАДАЧА --request-id КЛЮЧ`. Повторяй `--task` для уже существующих работ из разных проектов. Все эти работы автоматически входят в общий Гант периода. Чтобы включить обязательство без связи с результатом, используй `plan-add ПЛАН ЗАДАЧА`.
- Прочитай `okr-plan ПЛАН --limit 5` для списка целей, `okr-plan ПЛАН --view results --objective ЦЕЛЬ --limit 5` для результатов одной цели и `okr-plan ПЛАН --view tasks --result КР --limit 5` для её работ. `--view gaps` показывает цели без результатов, результаты без работ, работы плана без КР и недоступные карточки. Повторно использованная задача видна в общем Ганте один раз. Для закрытого периода используй снимок и проверь `hierarchyRecorded`, прежде чем отвечать об исторических связях.
- У старого результата с текстовой целью период может быть неизвестен. По явному выбору владельца включи его в цель того же направления через `okr-assign КР ЦЕЛЬ --revision РЕВИЗИЯ_КР`. Проверь ID результата и его историю через `okr-show`, а состав периода через `okr-plan`.

- Найди результат через `okr-list --match "часть цели или названия" --limit 5`. Для поиска в одном направлении добавь `--direction ID`. Прочитай `okr-show ID --limit 5`, чтобы увидеть единицу, целевое значение, последнее измерение и связанные задачи. Следующая страница доступна через `--offset 5`. Когда `measurement` равно `null`, измерений ещё нет.
- Для ответа об ориентире укажи `target` с единицей и ссылку на `path` со строкой `targetLine`. Если `target` равно `null`, ориентир не задан. Для связанной работы используй её название и ссылку `tasks[].path` из `okr-show`. Координаты фактического значения даёт `measurement.source`.
- Для отдельного результата вне плана доступна команда `okr-create "Название результата" --objective "Цель" --direction ID --unit "мин" --task ID_ЗАДАЧИ --request-id КЛЮЧ`. Существующие задачи ищи через `task-list --direction ID --match "название"`.
- Чтобы привязать ещё одну работу, используй `okr-link ID_РЕЗУЛЬТАТА ID_ЗАДАЧИ --revision REV` с ревизией из `okr-show`. Сверь ID задачи в результате и в каждом относящемся к запросу плане через `plan-show ID_ПЛАНА --task ID_ЗАДАЧИ`. Планы можно найти по названию через `plan-list --match "название"`.
- Для нового измерения прочитай строку заметки или проекта через `read "Notes/замеры.md" N N`. Сверь, что цитата относится к этому показателю и содержит число с единицей. Дату измерения возьми из протокола (она может стоять в заголовке) или из явного указания владельца. Если дата неизвестна, уточни её. Например, по строке «2026-11-22 восстановление заняло 18 мин» выполни `okr-measure ID --value 18 --date 2026-11-22 --source "Notes/замеры.md" --line N --quote "2026-11-22 восстановление заняло 18 мин" --revision REV`. При конфликте перечитай ключевой результат и строку источника.
- После записи проверь `okr-show ID`. Поле `measurement` показывает последнее измерение по дате. Если добавлен замер за более ранний день, найди его через `okr-show ID --history --limit 5`. История начинается с самых поздних дат. В ответе владельцу укажи значение с единицей и дату измерения. Для ссылки возьми путь и номер строки из свежего ответа команды, которая находит перемещённую запись и сдвинувшуюся строку. При отметке `source.unavailable` сообщи, что цитата сохранилась в истории и текущее основание требует сверки.
