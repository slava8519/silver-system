# Цель и измеримый ключевой результат

Используй CLI выбранного хранилища. Один ключевой результат хранит название цели, единицу измерения, ссылки на работы и историю измерений. Целевое значение задаёт владелец. Фактическое значение бери из записи с измерением.

- Найди результат через `okr-list --match "часть цели или названия" --limit 5`. Для поиска в одном направлении добавь `--direction ID`. Прочитай `okr-show ID --limit 5`, чтобы увидеть единицу, целевое значение, последнее измерение и связанные задачи. Следующая страница доступна через `--offset 5`. Когда `measurement` равно `null`, измерений ещё нет.
- Для ответа об ориентире укажи `target` с единицей и ссылку на `path` со строкой `targetLine`. Если `target` равно `null`, ориентир не задан. Для связанной работы используй её название и ссылку `tasks[].path` из `okr-show`. Координаты фактического значения даёт `measurement.source`.
- Для создания найди направление через `list --type direction --match "название"`, а существующие задачи — через `task-list --direction ID --match "название"`. Выполни `okr-create "Название результата" --objective "Цель" --direction ID --unit "мин" --task ID_ЗАДАЧИ --request-id КЛЮЧ`. Повторяй `--task` для других выбранных работ. Добавь `--target ЧИСЛО`, если цель измерения указана. При повторе того же запроса используй прежний ключ.
- Чтобы привязать ещё одну работу, используй `okr-link ID_РЕЗУЛЬТАТА ID_ЗАДАЧИ --revision REV` с ревизией из `okr-show`. Сверь ID задачи в результате и в каждом относящемся к запросу плане через `plan-show ID_ПЛАНА --task ID_ЗАДАЧИ`. Планы можно найти по названию через `plan-list --match "название"`.
- Для нового измерения прочитай строку заметки или проекта через `read "Notes/замеры.md" N N`. Сверь, что цитата относится к этому показателю и содержит число с единицей. Дату измерения возьми из протокола (она может стоять в заголовке) или из явного указания владельца. Если дата неизвестна, уточни её. Например, по строке «2026-11-22 восстановление заняло 18 мин» выполни `okr-measure ID --value 18 --date 2026-11-22 --source "Notes/замеры.md" --line N --quote "2026-11-22 восстановление заняло 18 мин" --revision REV`. При конфликте перечитай ключевой результат и строку источника.
- После записи проверь `okr-show ID`. Поле `measurement` показывает последнее измерение по дате. Если добавлен замер за более ранний день, найди его через `okr-show ID --history --limit 5`. История начинается с самых поздних дат. В ответе владельцу укажи значение с единицей и дату измерения. Для ссылки возьми путь и номер строки из свежего ответа команды, которая находит перемещённую запись и сдвинувшуюся строку. При отметке `source.unavailable` сообщи, что цитата сохранилась в истории и текущее основание требует сверки.
