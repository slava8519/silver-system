name: brain-vault
description: Подготовить локальное хранилище второго мозга, запустить рабочую оболочку или деморежим, создать учебные данные либо пересобрать индекс.
---

Из корня программы используй `python3 -m second_brain --vault "$VAULT"`, где `VAULT` — абсолютный путь выбранного хранилища. Выбирай команду по задаче.

| Задача | Команда и результат |
|---|---|
| Начать с пустого хранилища | `init` создаст папки и стартовые страницы. |
| Открыть админку | `work` откроет локальный сервер выбранного хранилища на порту 8766. Передай владельцу адрес из вывода. |
| Пройти три истории | `demo` создаст путеводитель на новом отдельном пути или продолжит существующий деморежим. Порт по умолчанию 8765. |
| Получить только три примера в Markdown | `examples` создаст их в новом каталоге. |
| Восстановить поисковый индекс | `rebuild` пересоберёт кеш из Markdown. |

Для учебной проверки именно рабочей оболочки выполни из корня программы `python3 examples/working_vault.py "$NEW_VAULT"` с новым путём. Затем запусти `work` для созданного каталога. Состав можно проверить через `overview --brief`.

Для пробы «разбери всё новое» используй `python3 examples/inbox_vault.py "$NEW_VAULT"`. Генератор подготовит три правила направлений, проекты, существующего участника и четыре новых файла для разбора.

Для проверки общих сроков в двух планах используй `python3 examples/planning_vault.py "$NEW_VAULT"`. В нём есть три направления, задачи с проектами и без проекта, планы с общими задачами.
