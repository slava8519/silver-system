# Группы людей и команда владельца

Запускай команды из папки программы с префиксом `python3 -m second_brain --vault "$VAULT"`. Выбранное хранилище хранит карточки людей, их групп и настройки владельца.

- Для «я», «моя карточка» и «моя команда» в запросе владельца прочитай `owner-context --limit 5`. Поля `owner` и `team` показывают явно выбранные карточки. Если поле равно `null`, выбор ещё не задан. Укажи основание выбора ссылкой на `path` со строкой `ownerLine` или `teamLine`. У каждого участника `members[].line` указывает строку в `team.path`, а `members[].path` ведёт к карточке человека. При `missing` укажи, что карточка по сохранённому ID недоступна. При `truncated` продолжи с `--offset 5`.
- Для решения «кому из моей команды поручить» проверь общие факты участников полученной страницы командой `person ID`. Если направление известно, добавь `--direction ID_НАПРАВЛЕНИЯ`. Для ссылки на роль возьми `path` и `start` из `evidence ID FACT_ID`, которая сверяет цитату с оригиналом. Если на странице подтверждения нет, проверь следующие страницы состава и фактов. Если нужная роль ни у кого в составе не подтверждена, сообщи это. Для такой проверки достаточно адресных команд `owner-context`, `person` и `evidence`. Полный протокол открывай по отдельной просьбе владельца. Доступность и назначение исполнителем требуют собственных оснований. Если выбор владельца или команды важен для решения и отсутствует, уточни его.
- Для добавления человека найди существующую карточку через `people --match "имя" --limit 5`. Используй её ID во всех группах. По просьбе о новой карточке выполни `person-create "имя" --request-id КЛЮЧ`. Тёзок различай по ID и подтверждённым сведениям.
- Ищи группы через `team-list --match "название" --limit 5`, а группы конкретного человека — через `team-list --person ID --limit 5`. При необходимости объедини фильтры. Для запрошенной новой группы вызови `team-create "название" --request-id КЛЮЧ`. При повторе одного запроса создания сохраняй тот же ключ.
- Прочитай `team-show ID_ГРУППЫ --limit 5`. Чтобы изменить состав, выполни `team-member ID_ГРУППЫ ID_ЧЕЛОВЕКА --add --revision REV` или используй `--remove` для исключения. Для переименования вызови `team-rename ID_ГРУППЫ "новое название" --revision REV`. Сверь результат через `team-show`. Все команды списка групп и состава поддерживают `--limit` и `--offset`.
- Для явного выбора своей карточки или команды сначала прочитай `owner-context`. Затем передай только запрошенные поля, например `owner-context --owner ID_ЧЕЛОВЕКА --team ID_ГРУППЫ --revision REV`. Для снятия выбора используй `--clear-owner` или `--clear-team` с прочитанной ревизией. Выбор команды и добавление человека в группу выполняются отдельно. При конфликте перечитай актуальную версию перед правкой.
