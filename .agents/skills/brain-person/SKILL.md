Используй префикс `python3 -m second_brain --vault "$VAULT"` из папки программы. Для вопросов «кто я в этом хранилище?» или «кто в моей команде?» начни с `owner-context --limit 5`. Для создания карточки человека, управления группой или выбора своей карточки и команды открой [команды людей, групп и владельца](references/teams.md).

Найди человека через `people --match "имя" --limit 5`. Для участников направления добавь `--direction ID`. Если подходящих людей несколько, уточни выбор.

Для сверки истории общих фактов у всех людей вместе с остальными карточками используй [общий проход по ваулту](../brain-vault/SKILL.md#обнови-все-сводки-и-истории).

- `person ID --limit 10` показывает общие факты человека и ревизию. Если запрошено одно направление, передай `--direction ID`. Следующая страница начинается с `--offset N`.
- Для источника конкретного факта выполни `evidence ID FACT_ID`. Приведи текущую формулировку и отдельно исходную цитату, если они различаются. Добавь `--personal` только в явно запрошенном личном контексте этого человека.
- Для запрошенного исправления выполни `person-correct ID FACT_ID --revision REV --text "новая формулировка"`. Устаревшая ревизия требует перечитать карточку и сверить изменение. `person ID --history` показывает сохранённые формулировки. Личные факты для просмотра и изменения открываются тем же явным флагом `--personal`.
