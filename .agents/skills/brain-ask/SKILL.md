Для вопроса о замере или ориентире ключевого результата OKR используй [команды ключевых результатов](../brain-plan/references/okr.md) в выбранном хранилище.

Для вопроса «кто я?» или «кто в моей команде?» прочитай `owner-context --limit 5` в выбранном хранилище. Если нужны и факты по делу, и состав своей команды, вызови `ask "$QUESTION" --brief --with-owner-context`. Для выбора кандидата «из моей команды» проверь общие факты участников через `person ID`. Если подходящей роли не видно, дочитай страницы состава и фактов и сообщи, нашлось ли подтверждение. [Как подтвердить роль и сослаться на состав](../brain-person/references/teams.md)

Запусти из корня программы. Подставь указанный путь хранилища в `VAULT`, а вопрос о фактах — в `QUESTION`. Просьбу оформить ответ со ссылками выполни по результату.

```sh
python3 -m second_brain --vault "$VAULT" ask "$QUESTION" --brief
```

По умолчанию ищи во всех направлениях. Добавляй `--direction ID`, только если владелец задал область поиска. ID по названию даёт `list --type direction --match "название" --limit 3` с тем же префиксом. Для нескольких направлений повтори флаг.

Для каждого элемента `items` верни отдельный пункт с названием `label`, фактом `answer` и ссылкой на `source.path` со строкой `source.start`. Если `answerTruncated` скрывает нужную часть, проверь её через `read "путь" начало конец`. Если `truncated` отмечает неполный список, уточни вопрос или увеличь `--limit`. При отсутствии подтверждения укажи, для какой части вопроса его не нашлось. Для отдельного поиска по ключевым словам среди карточек всех направлений доступна команда `search "фраза" --limit 3`.

На вопрос «Где мы сейчас по проекту и что изменилось?» передай в `ask` название или алиас проекта. У `kind=brief` находится текущая формулировка «Коротко», у `kind=event` — отдельное событие. Если сводка ещё не записана, на общий вопрос о положении проекта могут прийти `kind=status` и `kind=next_step` со строками шапки карточки. Указывай дату события, когда в записи есть `date`. В `source.origin` находятся координаты основания. При `available=false` первичная ссылка требует сверки. При совпадении названий проектов уточни направление или полное название. Для просмотра карточки проекта используй `show ID --brief`.

У факта из встречи есть `source.evidence`. Чтобы сверить текущую формулировку с оригиналом, передай его `personId` и `factId` в `evidence PERSON_ID FACT_ID`. Команда вернёт исходную цитату и её строку.

Для событий проекта за период передай дату в формате ГГГГ-ММ-ДД или две включительные границы «с ГГГГ-ММ-ДД по ГГГГ-ММ-ДД». Отбор идёт по дате самого события. Пустой ответ за период означает, что в отдельном журнале нет подходящих датированных записей. В прежних карточках подтверждённые изменения полей также могут оставаться строками в основном тексте проекта.
