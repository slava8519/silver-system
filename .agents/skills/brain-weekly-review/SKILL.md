name: brain-weekly-review
description: Подготовить или сохранить недельный обзор закрытого плана второго мозга по направлениям, со ссылкой на основание каждого вывода. Настроить формат выпуска или уточнить факт из обзора.
---

Для повестки, дайджеста, свободного отчёта или серии с версиями шаблона используй [навык отчётов](../brain-report/SKILL.md). Сохранённые обзоры закрытых планов также видны во вкладке «Отчёты».

Из папки программы вызывай `python3 -m second_brain --vault "$VAULT"` с командой ниже. Найди закрытый план через `plan-list --match "название" --limit 5`. Используй его ID. Просьба об обзоре сама по себе не закрывает активный план.

1. Выполни `weekly-review ID --start YYYY-MM-DD --end YYYY-MM-DD --timezone ЗОНА --limit 5`. Для прошедшей календарной недели укажи понедельник и воскресенье в часовом поясе владельца. Без явных дат команда берёт семь календарных дней по день закрытия включительно. При доступной оболочке этого vault добавь `--gantt-url URL`. Порт плагина можно посмотреть в `.obsidian/plugins/obsidian-gantt/data.json`, путь хранилища сверить в `URL/api/planning-vault`.
2. Прочитай следующие страницы через `--offset`, пока `truncated` истинно. Назови период событий и отдельно дату снимка. У каждого вывода, включая первую фразу резюме, поставь ссылку на выбранную строку **закрытого** плана или запись. Для вывода по нескольким работам сошлись на каждую участвующую строку либо изложи работы отдельными пунктами. Если сервер выключен, дай путь и номер строки. Различай согласованный срок, прогноз и подтверждённое завершение. Если источника не хватает, укажи пробел.
3. При `warningTotal` больше нуля проверь замечания через `--warnings --limit 5` и при необходимости `--offset`. Для просьбы посмотреть покажи результат в чате. Для нового выпуска повтори команду с теми же параметрами и `--save`. Дай ссылку на сохранённый Markdown в `Reports/`. Для переноса между выпусками укажи оба основания. При нескольких подходящих предыдущих выпусках выбери нужный через `--previous ID` по контексту запроса.

При просьбе изменить оформление обнови выбранные поля в `Settings/Formats/Weekly.md` и проверь предпросмотр. Поддерживаются `title` и `group_by` в YAML-шапке. Значение `direction` группирует по направлениям, `kind` — по виду вывода. Сохранённый выпуск может содержать ручные правки.

Если владелец подтверждает уточнение факта, перейди по ссылке из вывода к исходной работе. Дату исправь через [навык планирования](../brain-plan/references/schedule.md), событие — через [правку событий с основанием](../brain-plan/references/gantt.md). Перечитай результат и укажи строку исправления вместе с датой исходного снимка.
