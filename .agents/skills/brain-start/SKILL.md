# Первое знакомство со Вторым мозгом

На просьбу «Покажи, с чего начать» предложи выбор. В демо можно найти запасной ключ по готовой памятке. В своём хранилище можно записать факт, который хочется вспомнить, и найти его в новом чате. Если пользователь уже выбрал путь, начни с соответствующего шага. Для собственной записи уточни только недостающее, например папку или сам факт.

Для установки открой [README проекта](../../../README.md). В Codex работают из папки исходников с `second_brain/` и `.agents/skills/`. Доступность CLI можно проверить командой `python3 -m second_brain --help`. На Windows используй команду Python из инструкции по установке. Папку для пользовательских записей выбирают отдельно. Путь, указанный относительно текущего рабочего каталога, разреши до перехода в папку исходников. Если хранилище неясно, уточни путь.

## Попробовать на готовых записях

По просьбе запустить демо используй `python3 -m second_brain --vault "$DEMO" demo`. В `DEMO` передай новый, ещё не существующий путь или выбранную папку прежнего демо. Передай пользователю адрес из вывода. Предложи выбрать «Личное», затем вопрос «Где хранится запасной ключ из дорожного набора?» и нажать «Открыть источник». В том же путеводителе есть примеры по ИТ-проектам и парфюмерии. Для пробы со своей темой там есть «Добавить своё направление». Когда пользователь хочет начать отдельное рабочее хранилище, перейди к следующему разделу со своим путём. [Управление деморежимом](../brain-vault/SKILL.md)

## Сохранить и найти свою первую запись

Команды ниже выполняй из папки исходников с префиксом `python3 -m second_brain --vault "$VAULT"`, где `VAULT` указывает на выбранную папку записей.

1. Для нового хранилища по просьбе пользователя выполни `init` в выбранной новой или пустой папке. Для уже подготовленного хранилища начни с `overview --brief`. Если указана заполненная папка, назначение которой неясно, уточни его перед изменениями.
2. Возьми у пользователя сам факт и, если он указал направление, его название. В существующем хранилище найди направление через `list --type direction --match "название" --limit 3` и сверь совпадение. По просьбе завести новое выполни `create direction "название" --request-id КЛЮЧ`. Для отдельной заметки направление необязательно.
3. Сохрани текст командой `create note "заголовок" --body "факт пользователя" --request-id КЛЮЧ`. Для заметки в направлении добавь `--direction ID` с ID найденной или созданной карточки. Возьми `id` и `path` заметки из результата. Выделяй свой ключ каждой операции создания, при повторе той же отправки используй прежний ключ. [Создание карточек и направлений](../brain-record/SKILL.md)
4. Проверь заметку вопросом о записанном факте через `ask "вопрос" --brief`. Например, для записи о термометре подойдёт «Где лежит запасной термометр?». Найди ответ с ID этой заметки и прочитай `read "путь" начало конец`, подставив `source.path`, `source.start` и `source.end`. Ответь по прочитанной строке и дай ссылку на файл с номером строки. Если подходящей выдержки нет, попробуй `search "ключевые слова" --limit 3` и сверь фрагмент через `read`. Сообщи, если подтвердить ответ не удалось. [Вопросы по записям](../brain-ask/SKILL.md)

Для продолжения в новом чате дай пользователю короткую фразу с фактическим путём его хранилища и вопросом по сохранённой заметке. Ту же папку можно открыть в Obsidian, а саму запись — по пути из ответа.
