Запускай команды из папки программы с префиксом `python3 -m second_brain --vault "$VAULT"` для выбранного хранилища.

Если при разборе важно, кого владелец имеет в виду под «я» или «моя команда», прочитай `owner-context --limit 5`. В цитате из переписки установи, кто её произнёс. Когда автор, роль или исполнитель остаются неоднозначными, сохрани вопрос по этому фрагменту во входящих. [Выбор владельца и команда](../brain-person/references/teams.md)

**«Положи во входящие».** Для текста передай содержимое как UTF-8 на stdin команды `inbox-text` (необязательное название через `--title`). Для выбранного файла или скриншота вызови `inbox-file "путь к файлу"`. Сообщи путь из квитанции. Поле `alreadyProcessed: true` означает, что такой материал уже разобран и оригинал можно открыть по возвращённому пути. Разбор выполняй по отдельной просьбе владельца.

**«Разбери всё новое».** Сначала выполни `inbox-archive --apply --limit 5`, в том числе при повторном обходе пустой очереди. Команда переносит завершённые материалы и старые дубликаты, добавленные в папку напрямую. Если в `issues` есть записи, сообщи пути и причины. Затем вызови `inbox-new --limit 5`. Если есть работа, открой [порядок обхода и формат решений](references/queue.md). Самостоятельно доведи очередь до конца, включая уточнения владельца. После непустого обхода выполни `check --snapshot new --limit 5` и приведи итог проверки. Если `archived` больше нуля, сообщи количество перенесённых файлов и папку `Archive/Inbox/`. При изначально пустой очереди сообщи число открытых вопросов через `inbox-triage --limit 1`.

Для просьбы [«Обнови все сводки и истории»](../brain-vault/SKILL.md#обнови-все-сводки-и-истории) используй общий проход по уже записанным основаниям ваулта.

Для «разбери встречу и обнови Гант» сначала закончи разбор встречи. Затем передай в [оценку готовности работ](../brain-plan/references/readiness-estimates.md) дату события, проверенные цитаты со строками и путь сохранённого источника. Сопоставь их с работами по предмету встречи и результату.

Если владелец **отвечает на вопрос**, найди его через `inbox-triage`, сохрани ответ через `inbox-resolve ID "ответ"` и продолжи обход. Если просит настроить направление, используй `inbox-rules` и формат `inbox-rule` из порядка обхода.

**Одна встреча с указанным участником.** Вызови `inbox-read "Inbox/файл.md" --limit 20`. Если известен только заголовок, найди файл через `inbox --limit 5`. Следующие строки открываются через `--start`. У длинной строки есть `nextColumn`: передай это число в `--column` с номером строки и `--limit 1`.

Найди участника через `people --match "имя"`, направление через `list --type direction --match "название" --limit 3`. При совпадении имён уточни личность. Выбери существующий ID или явное создание. Сохраняй только подтверждённый дословный фрагмент с номером строки. Общий доступ ставь по указанной области, личные наблюдения помечай `personal`.

```sh
python3 -m second_brain --vault "$VAULT" inbox-process "$FILE" --revision "$REV" --person "$PERSON" --fact role "$DIRECTION" shared "$LINE" "$QUOTE" --remaining queue
```

Для нового человека замени `--person` на `--new-person "имя"`. Повтори `--fact` для других строк этого участника. Виды — `role`, `fact`, `observation`. При изменении входящего перечитай строки. Верни путь оригинала и ID человека. Для сверки самого исходника при разборе есть `original ID --start N --limit 5`.

При выборочном сохранении передавай `--remaining queue`. Codex получит остальные содержательные строки. Строка с выбранной цитатой целиком считается разобранной, в том числе при личной видимости факта. Если владелец завершил весь разбор, передай `--remaining finish`. Прежние вызовы без флага завершают разбор. Поле `remainingQueued` квитанции показывает, осталась ли работа.

В квитанции `inbox-process` и `inbox-apply` есть автоматическая проверка оригинала и файла разбора. При наличии `archiveIssue` сообщи об успешном разборе, покажи причину задержки переноса и повтори архивирование после устранения проблемы. Если `check.status` равен `issues` или `incomplete`, сообщи о сохранении и укажи путь и строку из замечания. [Полная проверка хранилища](../brain-vault/SKILL.md#проверить-хранилище)

Для просьбы убрать уже обработанное из Inbox выполни `inbox-archive --apply --limit 5`. Если просят только посмотреть, используй `inbox-archive --limit 5`. Источник проверяется по SHA-256, оригиналу и квитанции. Открытые вопросы и незавершённые работы остаются в Inbox до завершения разбора.
