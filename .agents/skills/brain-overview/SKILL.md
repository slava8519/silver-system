Запускай команды из корня программы с префиксом `python3 -m second_brain --vault "$VAULT"`, где `VAULT` — абсолютный путь выбранного хранилища.

- Для количества карточек вызови `overview --brief`. Для одного направления добавь `--direction ID`. Если дано название, найди ID через `list --type direction --match "название" --limit 3`.
- Для исследования связей используй карту в рабочей оболочке `/#map` или команды ниже. Чтобы просто перечислить проекты направления, достаточно `list --direction ID --type project --limit 5`. Папки и число карточек в них даёт `overview --folders --limit 10`.
- Для состояния конкретного проекта используй `show ID --brief`. Укажи записанное значение вместе с путём и строкой из `fieldSources`. Отсутствующий срок или статус обозначь как «не указан». Для проверки достаточно `read "путь" строка строка`.

## Карта связей

- `map --limit 5` покажет направления со счётчиками. Если известно название или другое имя, найди карточку командой `map search "Маяк" --limit 3`. Сверь тип, путь и устойчивый ID при совпадениях.
- `map focus ID` вернёт группы ближайших связей, их размер и несколько примеров. Для продолжения передай ключ из `groups[].key` в `map group КЛЮЧ --id ID --limit 5`. Для поиска внутри группы добавь `--match "фрагмент"`. Чтобы получить следующую страницу списка, укажи `--offset` с числом уже просмотренных записей. Переход к соседней карточке выполняй только при необходимости для ответа.
- Для утверждения о связи возьми `source` именно у этой связи. Проверь строку через `map source ID_ИСТОЧНИКА СТРОКА --revision РЕВИЗИЯ`, используя значения из `source`. Если файл изменился, перечитай связь перед повторной проверкой. В ответе укажи вид связи, путь и строку основания. Участие в закрытом плане относится к снимку этого плана.
- `map group unassigned` показывает записи без назначенного направления. `map group broken` показывает записи с недоступной ссылкой на направление. Не считай отсутствие направления ошибкой.
